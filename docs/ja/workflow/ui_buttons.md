# 🔘 UI ボタン

このページは、SpriteStudio のアニメーションでメニューや HUD のボタンを作る方に向けたものです。ポインタが乗ったときと押したときに反応し、無効なときは見た目を変え、絵の上でだけクリックを受けるボタンを作れます。`SpriteStudioButton` は、子に置いた `SpriteStudioPlayer2D` で描く Godot のボタン（`BaseButton`）です。`pressed`・`toggle_mode`・`disabled`・ショートカット・フォーカス・ボタングループは `Button` と同じように使えます。

## 作り方

1. ボタンを置きたい場所（`Control`・コンテナ・`CanvasLayer` の下など）に **`SpriteStudioButton`** ノードを追加します。
2. その子に **`SpriteStudioPlayer2D`** を追加し、いつもどおりインスペクターで `ssab` と `current_animation` を設定します。`.ssab` を 2D ワークスペースへドロップするとシーンのルートの下に置かれるので、できたプレイヤーをシーンドックでボタンの上へドラッグしてください。ボタンにプレイヤーが無いあいだは、シーンドックに警告が出ます。
3. ボタンの大きさを決めます。ハンドルをドラッグするか、`custom_minimum_size` を設定するか、コンテナに並べさせます。プレイヤーのキャンバスはその中に収まります（[絵の収め方](#絵の収め方) を参照）。プレイヤー自身の `position` と `scale` はボタンが設定します。
4. ほかのボタンと同じように、ボタンの `pressed` シグナルを接続します。

状態に応じた再生は、ゲームの実行中だけです。エディタでは、プレイヤーは自分のプロパティどおりに表示され、SpriteStudio の下部パネルでのプレビューもこれまでどおり使えます。

## 状態と再生するラベル

ボタンは、いまの状態に応じてプレイヤーのアニメーションの別の区間を再生します。

| 状態 | いつ |
| --- | --- |
| `normal` | 以下のどれでもないとき |
| `hover` | ポインタがボタンの上にあるとき |
| `pressed` | ボタンを押しているあいだ |
| `disabled` | `disabled` がオンのとき |
| `focused` | ボタンがキーボードやゲームパッドのフォーカスを持つとき（`Button` がフォーカスを表示する場合と同じ） |

同時に当てはまるときは、`disabled`・`pressed`・`hover`・`focused` の順で先のものを使います。

SpriteStudio で、プレイヤーが選んでいるアニメーションに、**状態と同じ名前のラベル**（`normal`・`hover`・`pressed`・`disabled`・`focused`、小文字）を付けてください。各状態は、そのラベルから、次のラベル（名前は問いません）の 1 フレーム手前まで（次が無ければアニメーションの終わりまで）をループ再生します。状態が変わると、新しい区間をすぐに先頭から再生します。

すべてのラベルをそろえる必要はありません。ラベルの無い状態は、次の順に代わりを使います。

| 状態 | 代わりに使うもの |
| --- | --- |
| `hover`、`focused`、`disabled` | `normal` |
| `pressed` | `hover`、それも無ければ `normal` |
| `normal` | アニメーション全体 |

そのため、`normal` と `pressed` のラベルだけでも、ボタンとして動きます。

### トグルボタン

`toggle_mode` をオンにすると、オンになっているトグルは**選択中**になります。選択中は、どの状態も先に `selected_` の付いたラベル（`selected_normal`・`selected_hover` など）を探し、無ければ付かないラベルを使います。ポインタが乗っていても、オンの見た目が残ります。押しているあいだは `selected_pressed`、無ければすぐ `pressed` を使います。`selected_` のラベルが無いトグルは、オンでもオフでも同じ見た目です。

## ほかのアニメーションを使う：`state_clips`

`state_clips` は、状態が読むラベルを置き換えます。各項目には `animation`、`label`、またはその両方を指定します。

```gdscript
@onready var button: SpriteStudioButton = $StartButton

func _ready() -> void:
    button.state_clips = {
        "normal": {"animation": "wait1"},    # wait1 全体
        "hover": {"animation": "walk"},
        "pressed": {"label": "push"},        # 選んでいるアニメーションの "push" ラベル
        "disabled": {"animation": "dead"},
    }
```

置き換えは、その状態へ代わりを求めてくる状態にも効きます。キーには `selected_` の付いた名前も使えます。`.ssab` に無いアニメーションやラベルを指す項目は、出力パネルに一度だけ報告し、その状態は置き換えが無いものとして再生します。

状態のラベルは、プレイヤーが選んでいるアニメーションから読みます。スクリプトからプレイヤーで別のアニメーションを選ぶと、以後はそのアニメーションから読みます。区間・ループ回数・再生と停止など、プレイヤーのほかの再生操作はボタンに任せてください。

## 絵の収め方

| プロパティ | 既定値 | 意味 |
| --- | --- | --- |
| `stretch_mode` | `STRETCH_FIT` | `STRETCH_FIT` はキャンバス全体をボタンの中に収め、`STRETCH_COVER` はボタン全体をキャンバスで覆います。`STRETCH_KEEP` は作者が作った大きさのまま、プレイヤーの原点をボタンの中心に置きます |
| `alignment_horizontal` / `alignment_vertical` | `ALIGNMENT_CENTER` | キャンバスとボタンの形が違うときの寄せ方。`ALIGNMENT_BEGIN`（左・上）、`ALIGNMENT_CENTER`、`ALIGNMENT_END`（右・下） |

収めるのは、選んでいるアニメーションのキャンバスです（[オーサリング時のキャンバス](../api/player.md#オーサリング時のキャンバス) を参照）。そのため、`state_clips` でキャンバスの違うアニメーションを再生しても、収め方は変わりません。キャンバスの中で絵をずらすには、プレイヤーの `offset` を使います。はみ出した部分を切り取るには、ボタンの `clip_contents` をオンにします。

## 絵の上でだけクリックを受ける

既定では、ボタンの矩形全体がポインタを受けます。絵の上でだけ受けるには、次のプロパティを使います。

| プロパティ | 既定値 | 意味 |
| --- | --- | --- |
| `hit_parts` | `[]` | ポインタを受けるパーツの名前。インスペクターにはプレイヤーのパーツ名が候補として出ます |
| `hit_on_artwork` | `false` | `hit_parts` が空のとき、プレイヤーが描くどのパーツの上でもポインタを受けます |

表示中のフレームで、そのパーツの `get_part_quad()` の輪郭の内側にある点だけが当たります。それ以外の場所では、ポインタはボタンの後ろへ通ります。キーボード・ゲームパッド・スクリーンリーダーからの操作は絞りません。`clip_contents` がオフなら、ボタンからはみ出した絵もポインタを受けます。

## 動きを減らす

動きを減らしたいプレイヤーのために、`reduced_motion` をオンにできます。オンのとき、各状態は区間を再生せず、先頭のフレームで止めます。停止なので、ユーザーデータやサウンドは発生しません。アニメーションに `reduced_motion` という名前のラベルがあれば、`normal` だけは代わりにその区間を再生するので、落ち着いたループに差し替えられます。`pressed`・`disabled` と `selected_` の区間は止めたままにして、その見た目を残します。

ボタン自身はシステムの設定を読みません。一部のプラットフォームでは Godot が設定を教えてくれます。

```gdscript
func _ready() -> void:
    $StartButton.reduced_motion = DisplayServer.accessibility_should_reduce_animation() == 1
```

## スクリーンリーダー

アニメーションは装飾として扱います。スクリーンリーダーに読ませる名前は、ボタンの `accessibility_name` プロパティで設定してください。

メンバーの一覧は、エディタのクラスリファレンス（**ヘルプ > ヘルプを検索…** で `SpriteStudioButton`）にあります。
